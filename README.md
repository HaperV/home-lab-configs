# 🏠 Home Lab: Network & Security Infrastructure
```
Учебный проект по развертыванию, автоматизации и защите серверной инфраструктуры на базе Ubuntu Server.
```

## 🎯 Цель проекта
```
Отработка практических навыков системного администрирования Linux, построения сегментированных сетей, автоматизации рутинных задач и применения принципов информационной безопасности (OPSEC) в тестовой среде.
```

## 🛠️ Стек технологий
```
- **ОС:** Ubuntu Server 22.04 LTS, Alpine Linux (тестовая ВМ)
- **Виртуализация:** VirtualBox
- **Сети:** Netplan, sysctl (IP-форвардинг), iptables (NAT/Masquerade)
- **Автоматизация:** Bash, Cron
- **Веб-сервер:** Nginx
- **Контроль версий:** Git / GitHub
- **Безопасность:** SSH (Ed25519), строгий `.gitignore`
```

## ✅ Что реализовано
```
### 1. Безопасный удаленный доступ
- Настроена аутентификация по SSH-ключам (алгоритм Ed25519).
- Полностью отключен вход по паролю (`PasswordAuthentication no`).
- Запрещен прямой вход под root (`PermitRootLogin no`).

### 2. Автоматизация бэкапов
- Написан Bash-скрипт для архивации конфигураций Nginx и веб-файлов.
- Скрипт запускается автоматически по расписанию через Cron.
- Бэкапы выполняются от имени пользователя `backup_user` с ограниченными правами (принцип минимальных привилегий).

### 3. Контроль версий и безопасность
- Все конфигурации хранятся в Git-репозитории.
- Настроен строгий `.gitignore` для предотвращения утечки чувствительных данных (SSH-ключи, логи, архивы бэкапов, файлы `.env`).

### 4. Сетевая инфраструктура и маршрутизация (L3)
- Настроен многодомный хост (multihomed host) с сегментацией сети через `netplan`:
  - `enp0s3` (WAN): статический IP в локальной сети для доступа к интернету.
  - `enp0s8` (LAN): `192.168.10.1/24` для изолированной внутренней сети `LAN_LAB`.
- Включен IP-форвардинг в ядре Linux (`net.ipv4.ip_forward=1`).
- Настроен NAT (Masquerade) через `iptables`, позволяющий машинам из внутренней сети выходить в интернет через внешний интерфейс сервера.

### 5. Интеграционное тестирование
- Развернута тестовая виртуальная машина (Alpine Linux) в изолированной сети `LAN_LAB`.
- Успешно проверена сквозная маршрутизация: пинг внешних хостов (`8.8.8.8`, `google.com`) из изолированной сети через шлюз на Ubuntu Server.
```

## 📁 Структура репозитория

```
home-lab-configs/
├── .gitignore                  # Правила исключения чувствительных файлов
├── README.md                   # Описание проекта
├── backup_nginx.sh             # Скрипт автоматического бэкапа Nginx
├── crontab_backup_user.txt     # Документация по cron-задаче
└── configs/                    # Зафиксированные конфигурации системы
    ├── netplan/
    │   └── 00-installer-config.yaml  # Настройки сетевых интерфейсов
    └── sysctl/
        └── sysctl.conf                 # Параметры ядра (IP-форвардинг)
```

## 🌐 Сетевая топология

```
[Интернет]
    |
[Домашний роутер / шлюз провайдера]
    |
[enp0s3: 192.168.0.X/24] ← Ubuntu Server (L3-маршрутизатор, NAT)
[enp0s8: 192.168.10.1/24]
    |
[Внутренняя изолированная сеть LAN_LAB: 192.168.10.0/24]
    |---> Тестовая ВМ (Alpine Linux, 192.168.10.10)
```
