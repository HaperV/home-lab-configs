# 🏠 Home Lab: Network & Security Infrastructure

Учебный проект по развертыванию и защите серверной инфраструктуры на базе Ubuntu Server.

## 🎯 Цель проекта

Отработка практических навыков системного администрирования Linux, автоматизации рутинных задач и применения базовых принципов информационной безопасности в тестовой среде.

## 🛠️ Стек технологий

- **ОС:** Ubuntu Server 22.04 LTS
- **Виртуализация:** VirtualBox
- **Языки/скрипты:** Bash
- **Веб-сервер:** Nginx
- **Планировщик:** Cron
- **Контроль версий:** Git / GitHub
- **Безопасность:** SSH (Ed25519), UFW (в процессе)

## ✅ Что реализовано

### 1. Безопасный удаленный доступ
- Настроена аутентификация по SSH-ключам (алгоритм Ed25519)
- Полностью отключен вход по паролю (`PasswordAuthentication no`)
- Запрещен прямой вход под root (`PermitRootLogin no`)

### 2. Автоматизация бэкапов
- Написан Bash-скрипт для архивации конфигураций Nginx и веб-файлов
- Скрипт запускается автоматически каждый день в 03:00 через Cron
- Бэкапы выполняются от имени пользователя `backup_user` с ограниченными правами (принцип минимальных привилегий)

### 3. Контроль версий и безопасность
- Все конфигурации хранятся в Git-репозитории
- Настроен строгий `.gitignore` для предотвращения утечки чувствительных данных:
  - SSH-ключи (`id_rsa`, `id_ed25519`, `*.pub`)
  - Системные файлы (`.bash_history`, `.bashrc`)
  - Архивы бэкапов (`*.tar.gz`)
  - Логи (`*.log`)
  - Файлы с секретами (`.env`, `*.key`, `*.pem`)
